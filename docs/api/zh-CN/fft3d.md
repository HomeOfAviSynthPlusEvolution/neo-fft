# FFT3D

[目录](README.md)

将图像分块、加窗并转换到频域，执行空间或时间降噪，再合成输出。也提供 Kalman 递推、锐化和去光晕。默认使用三个相邻帧；它不估计运动向量，也不做运动补偿。

[API 目录](README.md) · [计算原理](../../knowledge/zh-CN/fft3d.md) · [频谱缓存](../../knowledge/zh-CN/fft3d/spectra-cache.md)

## 调用方式

```text
core.neo_fft.FFT3D(
    clip [, sigma, beta, planes, bw, bh, bt, ow, oh,
    kratio, sharpen, scutoff, svr, smin, smax, interlaced,
    wintype, pframe, px, py, pshow, pcutoff, pfactor,
    sigma2, sigma3, sigma4, degrid, dehalo, hr, ht,
    l, t, r, b, opt, cache_frames, cache_mb, mt, ncpu, measure, fft_backend, kalman_warmup]
) -> VideoNode
```

以上是注册顺序；方括号表示可选参数，不是 Python 数组语法。只有 `clip` 必填，其余参数建议按名称传入。

输入须为固定格式、固定尺寸、至少一帧的平面 GRAY、YUV 或 RGB，具有 1 或 3 个平面；AviSynth 另支持四平面的 YUVA/RGBA。支持整数 8/10/12/14/16 位和 32 位浮点。每个选中平面的实际处理区域都必须通过下述块几何检查。

## 参数

### 输入、噪声与网格补偿

| 参数 | 类型 | 默认值 | 取值与作用 |
|---|---|---|---|
| `clip` | VideoNode | 必填 | 输入视频；输出尺寸、格式、帧数和帧率与它一致。 |
| `planes` | 整数数组 | 全部非 Alpha 平面 | 省略或 VS `None` 处理现有非 Alpha 平面；显式 `[]` 不处理任何平面，全部复制。索引须在实际平面范围内；重复索引不会重复处理。未选平面原样复制。 |
| `sigma` | 浮点数 | `2.0` | 非负，8-bit 尺度的噪声标准差。16-bit 时内部乘 256，float 时除以 255。 |
| `beta` | 浮点数 | `1.0` | 至少为 1。Wiener 增益下限为 `(beta-1)/beta`；越大保留的残余越多。Kalman 不使用该增益，但仍检查参数合法性。 |
| `sigma2`、`sigma3`、`sigma4` | 浮点数 | 各自继承 `sigma` | 非负，与 `sigma` 共同定义频率相关噪声曲线；四者相等时使用均匀模型。它们不是独立的时间帧噪声值。 |
| `degrid` | 浮点数 | `1.0` | 非负，控制从块 DC 推导出的窗形频谱分量的移除与恢复；0 关闭。不是只清除 DC。Kalman 递推本身不使用 degrid，但采样模型及启用的增强仍可能使用它。 |

对正 `pfactor` 的采样模型，`sigma1..4` 不参与普通 Wiener 噪声表；这里的 sigma1 就是 `sigma`。Kalman 是例外：初始化协方差仍使用 `sigma`。

### 块、时间模式与处理区域

| 参数 | 类型 | 默认值 | 取值与作用 |
|---|---|---|---|
| `bw`、`bh` | 整数 | `32`、`32` | 各至少为 2。以每个平面的样本为单位，不按色度比例缩小；可不同宽高。 |
| `bt` | 整数 | `3` | `-1..5`，含端点。不同值的实际算法见下表。 |
| `ow`、`oh` | 整数 | `-1`、`-1` | 任意负值表示对应块长除以 3 向下取整。非负时不得大于块长的一半。默认块 32 对应重叠 10、步长 22。 |
| `wintype` | 整数 | `0` | 0、1、2。分别使用余弦/余弦、平方根余弦/其三次方、矩形/余弦平方作为分析/合成窗的重叠肩部。 |
| `l`、`t`、`r`、`b` | 整数 | 各 `0` | 非负，从全分辨率画面的左、上、右、下排除的像素数；保留区域才参与滤波。不是输出裁剪。 |
| `interlaced` | 布尔 | `False` | 按场式行排列打包处理区域，再按逆排列写回。每个选中平面的处理区域高度必须为偶数；不改变帧率，不是去隔行。 |

| `bt` | 处理方式 | 输出帧 n 使用的普通时间邻域 |
|---:|---|---|
| -1 | 只做频域增强，不降噪 | n |
| 0 | Kalman 递推 | 有界预热或复用附近检查点；帧 0 原样复制 |
| 1 | 单帧空间 Wiener | n |
| 2 | 时间 Wiener | n−1、n |
| 3 | 时间 Wiener | n−1、n、n+1 |
| 4 | 时间 Wiener | n−2、n−1、n、n+1 |
| 5 | 时间 Wiener | n−2、n−1、n、n+1、n+2 |

`bt=2..5` 遇到邻域不完整的首尾帧时，整个请求退回 `bt=1`；不复制端点凑足邻域，也不改用其他较短的时间长度。短于 bt 的视频合法。启用采样噪声时，还可能另外需要 `pframe`。

`l+r` 必须小于输入宽度，`t+b` 必须小于输入高度。选中 YUV 色度时，边距须按对应轴的色度采样比例整除；仅处理亮度则无须为未处理色度满足这项对齐。每个选中平面的 ROI 至少能容纳 `bw×bh`，还必须满足不重复反射的 padding 范围。因此“区域不小于块”不是充分条件。

例如单轴长度 8、块长 8、重叠 0 无法容纳所需反射边界，会报错。几何与反射公式见[计算原理](../../knowledge/zh-CN/fft3d.md#2-块和工作图像)。

### 噪声采样与预览

| 参数 | 类型 | 默认值 | 取值与作用 |
|---|---|---|---|
| `pfactor` | 浮点数 | `0.0` | 非负；正值选择采样噪声，普通 Wiener 中线性缩放采样功率。Kalman 中仅用于开启采样，其正值大小不缩放采样功率。 |
| `pframe` | 整数 | `0` | 采样帧，超出范围时夹到首帧或末帧。有效预览使用当前输出帧 n，忽略此采样帧选择。 |
| `px`、`py` | 整数 | `0`、`0` | 非负的块网格索引，不是原图像素坐标。两者都为 0 时自动搜索；否则手动选择块。 |
| `pcutoff` | 浮点数 | `0.1` | 必须大于 0；噪声估计的高通评分权重尺度。 |
| `pshow` | 布尔 | `False` | 在采样或非均匀 sigma 模型生效时，输出当前帧选中噪声块的预览。均匀模型下此开关不生效。 |

模型优先级为：`pfactor>0` 的采样模型 → 四个有效 sigma 不相等时的频率模型 → 均匀 sigma。自动选择排除块网格四周各两层，只搜索 `bx=2..Nx−3、by=2..Ny−3`，所以每个相关平面的块网格至少为 5×5。手动坐标必须落在每个相关平面的网格内，色度网格通常更小。

有效预览优先于 bt、降噪、Kalman 和增强，不读取时间邻域或 pframe，也不推进 Kalman 状态。它只在 ROI 内显示所选块与可见区域相交的部分；ROI 内其他位置为零重建值，整数色度会恢复为其中点。选中 ROI 外及未处理平面仍复制输入（AVS 显式模式 1 除外）；没有文字叠加。

### Kalman 与增强

| 参数 | 类型 | 默认值 | 取值与作用 |
|---|---|---|---|
| `kratio` | 浮点数 | `2.0` | 非负；Kalman 中用来判断频谱变化是否触发状态重置。其他 bt 不使用，但仍检查原始值。 |
| `kalman_warmup` | 整数 | `8` | 0..2147483647，限制历史递推帧数，不含目标 n。仅有效 bt=0 使用，所有模式都检查原始值。0 表示冷启动不预热，但连续请求仍可沿用状态；没有自动或无限特殊值。 |
| `sharpen` | 浮点数 | `0.0` | 非负锐化强度；0 关闭。 |
| `scutoff` | 浮点数 | `0.3` | 大于 0；锐化频率权重的过渡尺度。 |
| `svr` | 浮点数 | `1.0` | 非负；调整增强权重中的垂直频率尺度，允许为 0。 |
| `smin`、`smax` | 浮点数 | `4.0`、`20.0` | `0≤smin≤smax`，按 sigma 的位深因子缩放后参与锐化增益；`smax=0` 不产生锐化增益。 |
| `dehalo` | 浮点数 | `0.0` | 非负去光晕强度；0 关闭。 |
| `hr` | 浮点数 | `2.0` | 大于 0；去光晕频率权重的尺度。启用去光晕时，其离散权重还须可归一化。 |
| `ht` | 浮点数 | `50.0` | 非负；去光晕功率尺度。不同于 sigma 和 smin/smax，它不按位深缩放。 |

增强一般作用于本帧恢复出的空间频谱；单帧均匀 Wiener 与增强有专门的融合计算顺序，不能理解为任意顺序串联几个滤镜。`bt=-1` 且两种增强强度都为 0 时仍经过加窗、FFT 和重建，不是逐字节旁路。

### 有界 Kalman 预热

AVS、VS 均接受 `kalman_warmup=8`；省略、VS `None` 或 AVS `Undefined()` 使用默认值。参数追加在旧宿主参数之后，AVS 中位于 y/u/v/a 之后。

对 n>0，只在 n-j≤W+1 时复用最近的已完成检查点 j≤n；否则用 L=0、C=Q=R0 初始化，消费 max(1,n-W)..n。默认冷请求第 10000 帧处理 9992..10000，共 9 帧；若有检查点 9996，只处理 9997..10000，共 4 帧；若有 9999，则只处理当前帧。连续请求通常保留长期历史，不会每 W 帧重置。帧 0 仍复制，AVS 显式模式 1 除外。

这个上限约束递推工作量。首次建立采样噪声模型时，可能额外读取窗口外的 pframe，因此 W+1 不是源帧回调总数或墙钟耗时保证。逐频点运动重置不等于整帧场景切换检测。

这是用请求顺序无关性换取有界冷启动成本：跳转、淘汰和并发调度可能选择不同历史并产生不同结果，同一帧在淘汰后重算也可能变化。私有状态保证不被并发写坏，不保证历史相同。少量预热可能暂时降低降噪能力；增加预热会增加上游计算，也不保证快速收敛。详见 [Kalman 状态与检查点](../../knowledge/zh-CN/fft3d/kalman.md)。

```python
out = core.neo_fft.FFT3D(clip, bt=0, kalman_warmup=8)
```

```avs
out = neo_fft_FFT3D(clip, bt=0, kalman_warmup=8)
```

### 执行与频谱缓存

| 参数 | 类型 | 默认值 | 取值与作用 |
|---|---|---|---|
| `opt` | 整数 | `0` | 1 选择本项目标量核；其他 int32 值使用自动 SIMD 路径，构建未启用 SIMD 时使用标量。数字不强制特定 ISA；1 也不强制第三方 FFT 为标量。 |
| `cache_frames` | 整数 | `-1` | -1 自动使用 `bt + 宿主并发数 - 1`：VS 创建时读取核心线程数，AVS 使用线程缓存提示，收到提示前按 1；0 关闭；正数限制缓存涉及的不同源帧数量。不是预分配整帧数量。 |
| `cache_mb` | 整数 | `128` | 正数为 MiB 预算，1 MiB=1048576 字节；-1 同样取默认 128；0 关闭。限制已计费缓存条目，不限制整个进程内存。 |

FFT3D 不创建内部工作线程，各平面在当前宿主调用线程中依次计算；VS 仍可并发请求多个输出帧。PocketFFT 内部也始终单线程。可选兼容参数 `mt`（布尔）、`ncpu`（整数）、`measure`（布尔）、`fft_backend`（字符串）仅由宿主接受，插件完全不读取、不校验其取值、不保存，也不改变线程数、规划或后端；FFT 固定使用 PocketFFT。详见[兼容参数](README.md#线程与执行参数)。

两个缓存上限同时生效；任一为 0 即关闭，低于 -1 报错。没有“无限”哨兵，较大的正数仍是有限上限。缓存只用于配置 `bt=2..5` 的普通处理，包括这些配置的首尾单帧回退；有效预览、`bt=-1/0/1` 不使用它。

预算不足时回到不使用缓存的块计算，不等待其他请求释放容量，也不改变滤波模式。成功进入缓存的同一行可由并发请求共享。详细规则见[频谱缓存](../../knowledge/zh-CN/fft3d/spectra-cache.md)。这些参数不控制 Kalman 检查点、VS 帧缓存或活动工作区。

## 返回值与帧属性

返回一个 VideoNode，宽、高、格式、帧数、帧率和帧属性来自当前输入帧。未选中平面（AVS 显式模式 1 除外）及选中平面的 ROI 外部逐字节复制，不增加缓存统计属性。

整数处理结果在最终转换时恢复整数色度中点、舍入并裁到位深范围。**选中 ROI 内的 float 输出裁到 `[0,1]`，包括 float YUV 色度**；因此负色度可能变成 0。复制区域保留原值。Kalman 的输出帧 0 直接复制各平面（AVS 显式模式 1 除外），不做这些转换。

## 最短示例

将插件路径替换为本机文件。以下使用空白源，无需额外视频读取插件：

```python
import vapoursynth as vs

core = vs.core
core.std.LoadPlugin(path="/path/to/neo-fft.dll")
clip = core.std.BlankClip(width=128, height=96, length=12,
                          format=vs.YUV420P8, color=[96, 128, 128])
output = core.neo_fft.FFT3D(clip, sigma=2.0, bt=3)
output.set_output()
```

下面两种调用复用上例的 `core` 和 `clip`，选其中一种作为输出：

```python
# 仅亮度、五帧 Wiener，允许最多 256 MiB 的行频谱缓存。
output = core.neo_fft.FFT3D(clip, planes=[0], bt=5, cache_mb=256)
output.set_output()
```

```python
# Kalman 递推；cache_mb 不控制它的状态检查点。
output = core.neo_fft.FFT3D(clip, bt=0, sigma=2.0, kratio=2.0)
output.set_output()
```

## 限制与常见错误

| 情况 | 行为或处理办法 |
|---|---|
| 希望显式表达默认平面选择 | VS 用 `planes=None`，AVS 用 `planes=Undefined()`；`planes=[]` 表示全部复制。 |
| 小色度平面或小 ROI 配大块 | 可能不满足块及反射几何；减小块或只选择所需平面。 |
| 用像素坐标指定 `px/py` | 它们是块网格索引，应按 ROI 导出的每平面网格选择。 |
| 邻域越界或视频短于 bt | 合法的 bt=2..5 请求退回空间模式；这不是非法 bt 的回退机制。 |
| 非法 bt、wintype、beta，负 sigma/边距，非法 planes | 创建失败。参数不参与当前模式，也不豁免原始类型和定义域检查。 |
| NaN、Inf、超出 float32 表示范围的数值参数 | 创建失败。除完全忽略的执行兼容参数外，整数参数及数组元素必须在 int32 范围内。 |
| 有限但极大的参数或像素 | 活跃计算仍可能溢出，创建或取帧失败；不会发布部分输出。 |
| 被消费的 float ROI 含 NaN/Inf | 取帧失败；纯复制区域不执行有限性扫描，Kalman 帧 0 同样直接复制。 |
| 把 `interlaced=True` 当成去隔行或自动读取场序 | 它只重排 ROI 行，不推断 TFF/BFF，也不改 `_FieldBased`。 |
| 把缓存预算当作进程峰值内存 | 活跃工作区、源帧、宿主缓存和其他状态另占内存。 |

计算定义见[FFT3D 原理](../../knowledge/zh-CN/fft3d.md)，模式细节见[噪声与增强](../../knowledge/zh-CN/fft3d/noise-enhancement.md)和 [Kalman](../../knowledge/zh-CN/fft3d/kalman.md)。

## 省略参数与空列表

VS 显式传 `planes=None` 等价于省略参数；AVS 用 `planes=Undefined()`，括号不能省略。两者都不是空列表：`planes=[]` 在两个滤镜中均表示不处理任何平面，校验配置后逐字节复制当前帧。默认处理全部现有非 Alpha 平面；AVS 省略或传 `Undefined()` 时，仍按 `y/u/v/a` 及其默认值选择。显式空列表覆盖 `y/u/v/a`，即使其中含模式 1 或非法模式值。

```python
core.neo_fft.FFT3D(clip, planes=None)  # 使用默认选择
core.neo_fft.FFT3D(clip, planes=[])    # 全部复制
```

```avs
neo_fft_FFT3D(c, planes=Undefined(), y=3, u=2, v=2) # 按 y/u/v/a 选择
neo_fft_FFT3D(c, planes=[])                         # 全部复制
```

## AviSynth

两个滤镜均接受平面 YUVA/RGBA，Alpha 索引为 3。Alpha 为全分辨率，样本缩放按亮度/RGB 处理，不采用色度中心偏移或子采样。未指定选择参数时处理现有非 Alpha 平面并复制 Alpha；`planes=[3]` 可单独处理 Alpha。

AVS 专用整数参数 `y/u/v/a` 按此顺序位于 `fft_backend` 与 `kalman_warmup` 之间。显式提供 `planes` 时以其为准，忽略这些模式；`planes=[]` 也算显式提供。否则未提供的模式默认 `y=u=v=3, a=2`；1 跳过写入，2 原样复制，3 处理。模式 1 不初始化对应输出平面，其像素内容不作保证，适用于后续只提取有效平面再组合的脚本；它省去该平面的复制，但不缩减输出帧的格式或分配。不存在的平面对应的合法模式无效果；未被 `planes` 覆盖时，其他模式值报错。RGB 中这些名字依次对应 R/G/B/A。`y=2,u=2,v=2,a=2` 在 FFT3D 中也表示全复制。VS 继续使用 `planes` 接口；以独立灰度 clip 保存的 Alpha 可单独送入滤镜。


AviSynth 使用同名共享参数，并在上述位置插入 y/u/v/a；音频与奇偶性来自输入，具体宿主要求见 [API 目录](README.md#avisynth-调用与构建)。

```avs
LoadPlugin("/path/to/neo-fft.dll")
c=BlankClip(width=128,height=96,length=12,pixel_type="YV12",color_yuv=$608080)
return neo_fft_FFT3D(c,sigma=2.0, bt=3)
```
