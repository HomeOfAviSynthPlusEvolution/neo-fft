# DFTTest：时空频谱与重建

[目录](README.md)

DFTTest 把同一空间位置的 T 帧 B×B 样本组成一个体积，以频谱功率决定残差增益，再恢复均值并合成为输出。默认 B=16、空间重叠 12、T=3、tmode=0。没有运动补偿，也没有跨帧原始频谱缓存。

[完整 API](../../api/zh-CN/dfttest.md) · [频谱模型](dfttest/spectral-models.md) · [时间重叠](dfttest/temporal-ola.md)

## 从输入到输出

1. 根据时间模式确定逻辑帧槽位，并请求去重后的源帧。活动 nlocation 另加入采样区间。
2. 按实际平面反射空间边界，将样本转换为 8-bit 幅度单位。
3. 乘时空窗 h，做体积 V=T×B² 的 FFT，存储 `[T,B,floor(B/2)+1]` 半谱。
4. zmean 开启时，计算 `g=Re(X[0])/Re(G[0])`，其中 G=FFT(255h)，残差 R=X−gG。
5. 按模型得到主参数 A，按 ftype 滤波 R，再加回 gG。
6. 做归一化逆 FFT；选择目标时间切片。tmode=0 用 `U*float(h*V)`（预计算合成窗），tmode=1 用 `(U*V)*h`，合成空间中心或全部重叠贡献。
7. 所有时间块合成完毕后裁取可见平面，一次输出转换或 dither。属性来自帧 n。

均值来自整个时空体积的 DC，并带有窗口权重，不能把每一帧单独去均值。FFT epsilon 和窗能量依赖分析缩放，不能移动 1/√V 后仍使用原噪声阈值。

## 两种时间语义

tmode=0 要求奇数 T，槽位为 `clamp(n−floor(T/2)+z,0,N−1)`；只重建中心 z。tmode=1 使用固定起点网格，允许偶数 T，重建所有覆盖 n 的时间块在 n 处的切片并相加。它不是把 tmode=0 多调用几遍。

空间 smode=0 在每个像素周围取奇数块，只输出块中心；smode=1 采用步长 B−O 的块网格和平方和归一化窗。完整几何见[块几何](shared/block-geometry.md)。

## 可复算的均值例子

取 B=1、smode=0、矩形空间/时间窗、T=3、zmean=true、ftype=2、sigma=0。在 8-bit 幅度单位下，三帧单像素为 `[1,2,6]`。

V=3，h=1/√3；窗口为常量，DC 导出的窗形均值对应三帧平均 `(1+2+6)/3=3`。类型 2 的零增益清除全部残差，恢复均值后，归一化逆变换与 Vh 合成得到中心输出 3。输入中心本来为 2。若 zmean=false，同样设置输出 0。

用 float 输入 `[1/255,2/255,6/255]`，相应中心结果是 `3/255`，且不裁剪。这个例子同时检验均值来自时间体积、sigma 在类型 2 是增益，以及逆变换尺度补偿。

## 模型与参数的位置

| 控制 | 改变的计算 |
|---|---|
| sbsize/smode/sosize、tbsize/tmode/tosize | 块原点、依赖、目标切片与贡献数 |
| swin/twin、sbeta/tbeta | 分析/合成窗及功率标定 |
| sigma、曲线、nlocation/alpha | 主功率阈值或增益表；采样优先于曲线 |
| ftype/f0beta、sigma2/pmin/pmax | 逐频点增益函数 |
| zmean | 过滤前后窗形均值的移除／恢复 |
| dither/seed | UInt8 最终量化，频谱不变 |

ftype=0/1 的主表为功率，2/3/4 为增益参数；与 FFT3D 的标准差平方规则不同。采样表只作用于 0/1，曲线可用于全部五种类型。

## 边界与精度

时间夹取保留重复槽位的不同窗位置。采样矩形完全在源平面内，不能利用输出 padding。planes=[] 仍校验配置，然后复制当前帧。只处理有限活动样本；整数最终裁剪，float 保留负色度与超范围结果。

固定 FFT 分组可能批量处理八个块，这不是多线程。当前所有块按调用线程执行，按时间起点再 Y 再 X 合成。相同算术配置下，请求顺序、宿主并发与 threads 等兼容参数的值不应改变结果；跨 SIMD/FFT 路径遵守各测试的数值预算，详见[执行精度](shared/execution-precision.md)。
