# FFT 方向、半谱与归一化

[目录](../README.md)

正变换采用负指数、不缩放；逆变换采用正指数并除以变换体积 V：

$$X_k=\sum_{j=0}^{L-1}x_j e^{-2\pi i jk/L},\qquad x_j=\frac1L\sum_{k=0}^{L-1}X_k e^{2\pi i jk/L}.$$

多维变换在各轴套用同一约定，V 是各变换轴长度之积。batch 轴只表示独立块，不属于变换体积。

## 存储什么

实输入的最后空间 X 轴压缩为 K=floor(Bx/2)+1。二维布局为 `[By,K]`；DFTTest 的三维为 `[T,B,K]`，X 连续。Y 和时间轴仍完整，偶数 T 不产生第二个压缩轴。

DC 是所有频率为零的系数。X 为偶数长度时有 Nyquist 列，但在多维中，该列的任意 Y/时间频点不一定都是实数。共轭关系要同时反转其他轴。滤波直接处理保存的复数系数，功率 `re²+im²` 不乘半谱重数 2。

## 手算

教学一维输入 `[1,0,0,0]` 的全谱为 `[1,1,1,1]`，保存半谱 `[1,1,1]`；归一化逆变换返回原输入。常量 `[2,2,2,2]` 的全谱为 `[8,0,0,0]`。这是变换算例，不是声称所有一维尺寸都是滤镜公开几何。

FFT3D 对 T 个空间频谱再做时间变换，时间逆变换的 1/T 和空间逆变换的 1/(BxBy) 各应用一次。DFTTest 变换体积 V=T×B²；分析窗已有 1/√V。逆变换后的合成在 tmode=0 使用 `U*float(h*V)`（创建时预计算合成窗），tmode=1 使用 `(U*V)*h`。理想代数相同，binary32 舍入次序不同。这个 V 补偿算法的尺度，不能当成重复归一化删掉。

例如 DFTTest B=1、T=3、矩形窗，幅度 `[1,2,6]` 先乘 1/√3。保留窗形均值而清除残差后，中心输出为 3；不是原中心值 2。完整链路见 [DFTTest](../dfttest.md)。

## 计算路径与误差

当前使用 PocketFFT。`opt=1` 只约束自有算子，FFT 分派独立。固定分组的批量 FFT、专用 codelet 和中心切片逆变换是相应数学定义的实现优化，不改变时间轴与 batch 轴的含义。不同算术路径可能有不同舍入；不能以常量例子的精确结果证明所有频谱逐位相同。参见 [KernelInfo](../kernel-info.md)及[精度边界](execution-precision.md)。
