# 执行、资源与精度边界

[目录](../README.md)

一个输出请求消费声明的输入帧，并拥有自己的可变工作区。FFT3D 平面和 DFTTest 块都在宿主调用线程内执行；PocketFFT 内部同样单线程，没有内部线程池。宿主可并发发起多个输出请求；threads 等旧执行参数仅在宿主签名中接受，不读取或传入核心，不影响调度或保留预算。

## 确定性依赖什么

配置、窗、FFT 计划、发布后的噪声模型不可变。频谱缓存项是只读输入；Kalman 检查点恢复成请求私有状态。DFTTest 按时间块起点、空间 Y、空间 X 的顺序累加；FFT3D 保留水平后垂直的合成顺序。dither 使用输出坐标而不是工作线程身份。

同一构建、后端、分派及算术配置下，非 Kalman 模式应在正序、并发、缓存冷热时一致。Kalman 是例外：kalman_warmup 限制冷启动补算，检查点与请求历史决定起点，淘汰或并发调度可能改变输出。请求私有状态提供并发内存安全，不代表任意访问顺序的像素确定性。

改变标量／Highway、FFT 配置或算术分组时，可能改变舍入。误差应分别评估整数 LSB、浮点绝对误差、阈值分支和输出裁剪；不使用一个全项目万能 epsilon。原版黑盒比较还受模式、数据尺度和随机噪声定义影响。历史测试的容差是该测试范围的证据，不是所有输入的定理。

## 三种不同预算

| 对象 | 保留规则 | 不包含什么 |
|---|---|---|
| 空闲工作区 | 每实例跨平面最多一个，最多 64 MiB | 活动请求的独立工作区、宿主帧 |
| FFT3D 原始频谱行 | cache_mb 默认 128 MiB，另受 cache_frames 限制 | 工作区、宿主缓存、请求登记等，见缓存专题 |
| Kalman 检查点 | 默认 max(64 MiB, 一个完整检查点加元数据)，最多四个 | 已淘汰但仍被请求持有的旧快照与私有状态 |

例如宿主同时处理四帧，空闲工作区上限 1 并不会把它们强制串行：四个请求可分别分配活动工作区。也不能据 64 MiB 推断进程峰值。频谱缓存准入失败走私有计算；真正的内存分配失败仍是错误。

## 生命周期和错误

源帧只在拥有有效宿主引用时读取，不在缓存锁内取帧。模型或行谱只有完全生成后才发布；失败的输出或部分 Kalman 状态不发布。Kalman 分阶段回放并释放上一源帧，但宿主自身的历史元数据、上游缓存不属于插件内存保证。

配置类型、范围、几何或派生表错误在创建阶段报告；活动样本、FFT 或输出运算溢出在取帧阶段报告。未处理平面是复制，AVS 显式模式 1 则跳过写入；算法参数即使在当前模式下不参与计算仍须通过适用的原始校验；完全忽略的执行兼容参数除外。输出始终带源帧 n 的属性。
