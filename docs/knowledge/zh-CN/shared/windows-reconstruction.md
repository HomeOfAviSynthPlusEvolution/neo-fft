# 窗口、能量与重建

[目录](../README.md)

分析窗控制块边缘进入 FFT 的幅度；合成窗决定逆变换后的重叠贡献。窗口必须成对理解，不能合成后再随意除以贡献次数来掩盖尺度错误。

## FFT3D 的肩部窗

重叠长度 O 的左右肩部，j=0..O−1：`cL=cos(π(j−O+0.5)/(2O))`，`cR=cos(π(j+0.5)/(2O))`。中央区域全为 1，O=0 不求肩部式。

| wintype | 分析 a | 合成 s |
|---|---|---|
| 0 | c | c |
| 1 | √c | a³ |
| 2 | 1 | c² |

相邻肩部满足 `aL*sL+aR*sR=1`（理想算术）。二维分析乘纵横分析窗，合成保持先横后纵顺序。空间逆 FFT 已除块面积，合成不再除面积。以 O=1 为例，cL=cR=√0.5，两个单位样本的身份贡献分别为 0.5，合成为 1。

```text
a = [0.27105140069342415, -0.433297939234486060,
     0.218122999543110620, -0.065925446388030898,
     0.010811742098372268, -7.7658482522509342e-4,

I0a(x):
    numerator = denominator = total = 1
    for k = 1..14:
        numerator *= x/2
        denominator *= k
        v = numerator/denominator
        total += v*v
        if v <= 1e-8: break
    return total
```


负但有限的窗值可用；活动窗计算溢出或归一化分母为零则创建失败。

## 从原始窗到时空体积

smode=0 保留原始空间窗 sw。smode=1 按步长 S=B−O 对同相位样本平方求和，再做 `sw[j]=raw[j]/sqrt(sum raw[k]²)`。求和顺序是 j,j−S,...，再 j+S,j+2S,...。tmode=0 使用原始时间窗 tw；tmode=1 按时间步长做同样的平方和归一化。

```text
V = T*B*B
h[z,y,x] = float(tw[z]*sw[y]*sw[x]/sqrt(V))
E = sum_float_in_z_y_x_order(h*h)
wscale = 1/E
G = FFT(255*h)
```

表系数先以 double 相乘再存为 float；E 用存储的 float 值顺序累加。均值模板要求有限，zmean=true 还要求 Re(G[0])≠0。例如 flat-top、B=4、零空间重叠会得到符号窗，模板 DC 可为零；此时关闭 zmean 可使用该有限窗，但不能保留 zmean 后除以零。

分析输入为 q*h，归一化逆变换结果为 U。tmode=0 预计算 `float(h*V)`，合成时计算 `U*float(h*V)`，只取 z=floor(T/2)；tmode=1 先缩放逆变换结果，再按 `(U*V)*h` 合成每个覆盖块的目标切片。这两种乘法次序理想代数等价，但 binary32 舍入不同。smode=0 只取空间中心，smode=1 加整个块。最终一次量化，不能逐块量化。

B=2,O=1,T=1、矩形窗时，sw=1/√2，h=1/4，E=1/4，wscale=4。一个身份块贡献 q/4，四块合成 q。sigma=8 的类型 0 阈值是 `8/wscale=2`，不是 64。

tmode=0 的身份增益在空间 OLA 下为 `tw[center]²`，中心模式另乘 `sw[center]^4`，不能一概声称身份为 1。例如 twin=6 的中心值为 1.000001。tmode=1 的时间相位归一化使理想总时间增益为 1，仍保留空间中心窗的增益。详见[时间重叠](../dfttest/temporal-ola.md)。
