# 块、重叠与边界几何

[目录](../README.md)

以下按单轴说明，垂直轴独立套用。W 是实际处理平面的长度，B 是块长，O 是重叠，S 是步长。色度使用自己的宽高，但块尺寸不会自动按色度比例缩小。

## FFT3D

负 O 先归一化为 floor(B/3)，其余要求 `0≤O≤floor(B/2)`，B≥2。几何为：

```text
S = B-O
N = ceil((W-O)/S)+2
P = N*S+O
offset = S
block_origin(i) = i*S, 0<=i<N
```

W 为选中平面 ROI 的长度，至少为 B，且反射也必须合法。例 W=64,B=8,O=2：S=6,N=13,P=80，左 pad=6、右 pad=10。可见区是 `[6,70)`。ROI 是过滤区域，输出不裁剪。选中色度时，亮度单位的边距须整除相应子采样比例。

## DFTTest

中心模式 smode=0 要求奇数 B，c=floor(B/2)，P=W+2c、offset=c、S=1，共 W 个块，各自只输出局部中心。W=5,B=3 时 P=7，五个中心恰对应五个输出样本。

空间重叠模式 smode=1 使用：

```text
S = B-O
A = 2*max(S,O)
P = B*ceil(W/B)+A
offset = floor((P-W)/2)
N = floor((P-B)/S)+1
```

要求 `0≤O<B`；O>floor(B/2) 时 B 必须能被 S 整除。W=17,B=8,O=6 得 S=2,P=36,offset=9,N=15。尾部可能有未使用的扩展条带，但可见区域必须被完整覆盖。它不是 FFT3D 的网格公式。

## 一次反射

扩展坐标减去 offset 得 j，读取坐标为：

```text
j < 0       -> -j
0 <= j < W  -> j
j >= W      -> 2*W-2-j
```

例如 `[a,b,c,d]` 左右各扩展两点得到 `[c,b,a,b,c,d,c,b]`，端点不重复。两侧 padding 都不得超过 W−1；不满足时创建失败，不反复套反射公式。小色度平面因此可能比亮度更早触发错误。

FFT3D 场式打包把高度 8 的 ROI 行排为 `[0,2,4,6,7,5,3,1]`，在整张打包图上做上述几何，最后逆排列；不是分别处理两幅半高图。DFTTest 时间端点使用夹取而不是空间反射，见[时间重叠](../dfttest/temporal-ola.md)。

这些整数几何先检查溢出，再分配缓冲。增大重叠会增加块数与频谱工作量，即使输出分辨率不变。公式定义见 [FFT3D 原理](../fft3d.md)、[DFTTest API](../../../api/zh-CN/dfttest.md)。
