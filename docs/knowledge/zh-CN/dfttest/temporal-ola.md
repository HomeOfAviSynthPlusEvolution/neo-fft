# DFTTest 时间重叠合成

[目录](../README.md)

`tmode=1` 将时间当成固定网格的块轴。一个输出帧会收到所有覆盖它的时间块的贡献；它不依赖上次请求了哪帧。T=tbsize、O=tosize、D=T−O，N 为片长。

[DFTTest 主文](../dfttest.md) · [API](../../../api/zh-CN/dfttest.md)

## 起点网格与端点

```text
A = -max(D,O)
s_j = A+j*D, j>=0
选取所有 s_j<=n<s_j+T
目标切片 z = n-s_j
第 k 个输入槽位 = clamp(s_j+k,0,N-1), k=0..T-1
```

负锚点 A 决定相位，不能把第一次被请求的帧当作网格起点，也不能先夹取 s_j。源帧去重仅减少宿主取帧；重复逻辑槽仍参与不同窗位置。

| T,O,n | 覆盖起点 | 目标 z |
|---|---|---|
| 4,2,0 | −2,0 | 2,0 |
| 4,2,3 | 0,2 | 3,1 |
| 5,2,0 | −3,0 | 3,0 |
| 5,2,2 | 0 | 2 |
| 4,0,4 | 4 | 0 |

N=5,T=4,O=2,n=4 时，起点 2、4 对应槽位 `[2,3,4,4]` 和 `[4,4,4,4]`。最后一帧重复并不使两块等同。一般依赖并集不超过 min(N,2T−1) 个真实帧，另加活动采样依赖；没有 Kalman 式递推状态。

## 时间窗与合成

对原始时间窗 r，在相同步长 D 的每个相位上归一化：`tw[z]=r[z]/sqrt(sum r[k]², k≡z mod D)`。按 z,z−D,... 然后 z+D,... 的次序求和。O=0 也归一化，非零 r 变成符号；零能量相位报错。

体积窗 `h=tw*sw_y*sw_x/sqrt(TB²)` 决定新的 wscale。过滤完整体积后，以归一化逆结果 U 的目标切片产生 `(U[z]*TB²)*h[z]`。起点升序，再空间 Y、X 升序累加；smode=0 的中心也必须相加，不能覆盖前一时间块。全部完成后才转换/dither。

## 两个可复算例子

B=1、矩形窗、T=4,O=2：tw 各项为 1/√2，h=1/√8，E=1/2,wscale=2。每个输出有两个覆盖块，身份路径各贡献原像素的一半，合成不需再除 2。

若幅度序列为 `[0,2,4,6,8,10]`，zmean=true、ftype=2、sigma=0，则 n=2 收到起点 0 的四帧均值 3 和起点 2 的四帧均值 7，各乘 1/2，输出 5。原像素为 4，区别来自块均值过滤，不是合成增益错误。

T=5,O=2 则 D=3，tw=`[1/√2,1/√2,1,1/√2,1/√2]`，E=3/5,wscale=5/3。n=2 只有一个权重 1 的贡献；n=3 有两个权重 1/2 的贡献，不能用固定“重叠块数”标定所有帧。

## 准入与精度

T 为 1..15 且 T≤N；O 在 `[0,T)`，重叠超过 floor(T/2) 时要求 T 被 D 整除。T=6,O=4 合法，T=5,O=3 非法。即使 `planes=[]` 也检查这些规则。tmode=0 仍要求奇数 T，使用原始时间窗和中心切片；两个模式不能承诺对所有窗逐位相同。

同一算术配置必须支持反序、重复和并发请求。当前没有时间块缓存；所有覆盖块按定义计算。数值误差与阈值边界见[执行精度](../shared/execution-precision.md)。
